# Genesis Security (ภาษาไทย)

**ระบบป้องกันการโจมตี AI Agent และ Multi-Agent แบบรันจริง**

> ข้อมูลจากภายนอกเป็นข้อมูลเสมอ ไม่เคยเป็นคำสั่ง
> Claude Skill = สมอง, Python = ร่างกาย, ไม่รวมกัน

Agent อ่านหน้าเว็บ ไฟล์ อีเมล และข้อความจาก agent ตัวอื่น แล้วลงมือทำจริง เช่น รันคำสั่ง ส่ง request เขียน memory หรือส่งคำสั่งซื้อขาย ข้อความเหล่านั้นอาจมีคำสั่งแฝงจากคนอื่นอยู่ Genesis Security วางอยู่ระหว่าง agent กับ tool และบังคับให้ทุก action สืบย้อนกลับไปหาเจ้าของได้

## ติดตั้งและลองใช้

```bash
pip install git+https://github.com/ElmatadorZ/Genesis-security.git
genesis-security demo          # ดูระบบหยุดการโจมตี 12 แบบ
genesis-security redteam       # ยิงโจมตี 45 แบบใส่เครื่องตัวเอง (ต้องได้ 0 failures)
```

สร้าง key (บน Windows PowerShell):

```powershell
$env:GENESIS_SECURITY_KEY = genesis-security keygen
```

## ใช้งานขั้นต่ำ

```python
from genesis_security import GenesisSecurityGate, Tier

gate = GenesisSecurityGate.from_env(
    owner_confirm=lambda v, ctx: input(f"{v.reason}\nอนุญาตไหม? [y/N] ") == "y",
)

@gate.guard("delete_file")
def delete_file(path): ...

delete_file({"path": "a.md"}, {"agent": "main", "origin_tier": Tier.T1})  # คุณสั่ง → ถามยืนยัน
delete_file({"path": "a.md"}, {"agent": "main", "origin_tier": Tier.T3})  # เว็บสั่ง → ถูกบล็อก
```

## แนวคิดหลัก

| ระดับ | แหล่ง | สิทธิ์ |
|---|---|---|
| T0 | system prompt, config ของเจ้าของ | กำหนดนโยบาย |
| T1 | เจ้าของสั่งโดยตรง | สั่งงาน, ยืนยัน Human Gate |
| T2 | agent ภายในที่ลายเซ็นถูกต้อง | ส่งผลลัพธ์/คำขอ ขยายสิทธิ์ตัวเองไม่ได้ |
| T3 | เว็บ, ไฟล์, อีเมล, tool output, agent ที่ไม่ได้เซ็น | เป็นข้อมูลเท่านั้น |

วงจรตรวจ L0–L5: ระบุแหล่ง → สแกนคำสั่งแฝง → **action มาจากเจ้าของไหม (ด่านหลัก)** → secret/โฮสต์/shell/สิทธิ์ → ย้อนกลับไม่ได้ต้องถามเจ้าของ → ตัดสิน แล้วบันทึกลง audit ที่แก้ย้อนหลังไม่ได้

ผลตัดสินมี 4 แบบ: `ALLOW` อนุญาต · `ALLOW_SANITIZED` อนุญาตแบบทำความสะอาดแล้ว · `HOLD` รอเจ้าของ · `BLOCK` ปฏิเสธ

## ประยุกต์ใช้กับอะไรได้บ้าง

- **บอทเทรด (MT5, exchange):** ข่าวหรือ agent อื่นสั่งเปิดออเดอร์เองไม่ได้ และ agent ให้สิทธิ์ `trade:live` กับตัวเองไม่ได้
- **Coding agent:** บล็อก `;`, `|`, `$()`, `python -c`, `git -c` และทุกคำสั่ง shell ต้องผ่านการยืนยันก่อน
- **Agent ค้นข้อมูล:** อ่านเว็บได้ทุกที่ แต่เว็บสั่งให้ส่งข้อมูลออกหรือลงมือทำอะไรไม่ได้
- **Multi-agent council (Genesis Mind, SkynetClaw):** กันการปลอมตัว การส่งข้อความซ้ำ การขยายสิทธิ์ และการวนลูป
- **Memory ระยะยาว:** ข้อมูลจากเว็บเข้าได้เฉพาะข้อเท็จจริง ฝัง "กฎ" ไม่ได้

## ข้อจำกัดที่ต้องรู้

- ตัวสแกนคำ (L1) จับวลีที่เปลี่ยนสำนวนไม่ได้ทั้งหมด แต่ L2 ยังบล็อก action ที่ตามมาได้ครบ
- ต้องตั้ง `origin_tier` ให้ถูกในโค้ดของคุณเอง ถ้าไม่แน่ใจให้ใช้ T3
- ป้องกันได้เฉพาะ tool ที่ส่งผ่าน gate
- secret ที่เข้ารหัสแบบพิเศษ (rot13, gzip) ที่ส่งไปโฮสต์ที่คุณ allowlist ไว้เองจะผ่านได้ จึงควรเก็บ allowlist ให้สั้นที่สุด
- ไม่ใช่ sandbox ต้องใช้คู่กับการจำกัดสิทธิ์ของระบบปฏิบัติการ
